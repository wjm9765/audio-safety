## 1. The question

Hold the spoken words and the original recording fixed, change only an acoustic
property, and ask whether Qwen2-Audio-7B-Instruct changes whether it emits an
**explicit refusal marker** — and if so, trace where inside the model that change
is carried.

`pv_locked` vs `pv_standard` are two renderings of the **same source recording**
through the **same** phase-vocoder pitch/vocoder route, differing only in phase
handling. 500 paired items (350 harmful / 150 benign).

**Scope limit fixed in advance (`rules.md` §2):** the endpoint is the presence of
a frozen literal refusal marker. Marker absence is not compliance, not
acceptance, and not a successful harmful answer. No jailbreak success rate is
measured anywhere in this work.

## 3. Results

### 3.1 The phenomenon (Stage 0, all 500 pairs)

| stratum | n | paired disagreement (primary) | R→NR | NR→R | net refusal difference (secondary) |
|---|---:|---|---:|---:|---|
| harmful | 350 | **0.197** [0.154, 0.240] | 41 | 28 | −0.037 [−0.086, +0.009] |
| benign | 150 | **0.220** [0.160, 0.287] | 16 | 17 | +0.007 [−0.067, +0.080] |

The primary CIs exclude zero in both strata; the secondary net-difference CI
includes zero in both.

**Not an equivalence claim.** Failing to reject is not establishing no
difference — the harmful CI still permits an 8.6-point decrease. The supported
statement is that marginal-rate testing *fails to reveal* the within-pair churn.

Exact McNemar p = 0.148 (harmful) / 1.000 (benign): switching is bidirectional.
Conditional on the start state the NR→R limb is the stronger one in harmful items
(0.286 [0.204, 0.378] vs 0.163 [0.119, 0.210]).

Failure-excluded sensitivity: 0.185 [0.144, 0.226] harmful, 0.228 [0.159, 0.297]
benign — decoding failures (15/1000, 1.5%) do not carry the effect.

An earlier Exp2 sweep on the **same 500 items and renders** under an unpinned
revision gave 0.210 / 57 / 47 against this run's 0.204 / 57 / 45. This is a
**robustness rerun, not an independent replication**.

### 3.2 Content (Stage 6, 60 audited pairs)

The pre-registered `wer ≤ 0.20` gate is **mis-specified for this model**: Qwen
answers a transcription prompt with a carrier phrase (*"The exact words spoken in
the audio are: '…'"*), whose tokens count as WER insertions. One pair scores
`token_overlap = 1.000` and `wer = 1.000` simultaneously. 112/120 transcripts are
carrier-quoted, so the gate reads 0/60 for reasons unrelated to content.
`rules.md` §5 Stage 6 already forbids using this audit as an exclusion filter, so
no downstream result depends on it.

Carrier-stripped (post-hoc; **cannot make the registered gate retroactively
pass**): WER 0.316 vs 0.376; token overlap 0.820 vs 0.812 (paired Δ −0.008);
content-faithful 41/60 vs 40/60; 22/60 pairs byte-identical in both arms.

Instability stratified by measured content preservation: all audited 0.200
(n=60); **both arms content-faithful 0.243 (n=37)**; not both faithful 0.130
(n=23); **identical transcript in both arms 0.182 (n=22)**.

L10 content-patch audit (n=60): ΔWER +0.024 / −0.041, Δoverlap −0.019 / +0.015,
Δdonor-overlap +0.110 / +0.067, content-faithfulness verdict changed in **0/60**.

### 3.3 Input level (M1, 40 pairs)

Endpoint gate 80/80 exact, max margin error `0.00e+00`.

Whisper's log-Mel floor is `max(log_spec, log_spec.max() − 8.0)`, a **global**
clamp, so any edit that moves the peak level shifts the zero-padded tail by the
same amount. Measured: padded delta `0.016398` = change in global max `0.016398`.
The padded tail carries **34.8% of ‖ΔF‖ on average, up to 0.931**.

| component | ‖comp‖ | median transport fraction | marker flip |
|---|---:|---:|---:|
| `pad_floor` | 23.3 | 0.016 | 2.5% (1/40) |
| `temporal_fast` | 36.3 | 0.236 | 12.5% |
| `temporal_slow` | 36.8 | 0.306 | 20.0% |
| `time_shift` | 51.8 | 0.419 | 10.0% |
| `wrong_item` | 51.8 | 0.381 | 7.5% |

Speech × pad 2×2 interaction (run `exp3_20260730_0200_m1_interaction`): pad main
effect +0.013 ±0.055, **interaction −0.004 ±0.128**, speech share 103.5%. The
`all` effect is attributable to the valid speech frames, not the global-floor
pathway. Norm share is not causal importance.

M1 does **not** establish input-level item-specificity at n=40: the continuous
measures for the temporal components, `time_shift` and `wrong_item` overlap
heavily, and donor-aligned means are outlier-dominated (`wrong_item` mean +0.719
vs median +0.053).

### 3.4 Representation probes (Stage 2, 240 cells / 120 items)

Cross-fitted, item-grouped AUROC for predicting the generated marker:

| site | AUROC |
|---|---|
| audio encoder (32 layers) | 0.52–0.63 (peak L18 0.629) |
| projector | 0.604 |
| LLM audio-span mean | 0.61 → 0.69 |
| LLM `t_AB` | 0.55 → **0.836** (L27), monotone |

Role-stratified: encoder **0.512 (chance) for harmful** / 0.678 benign; `t_AB`
0.838 harmful / 0.764 benign. These are observational localization only
(`rules.md` §5 Stage 2). Part of the AUROC reflects which *items* refuse at all.
The rising-toward-`t_AB` profile matches Qwen's documented late-fusion /
final-token bottleneck (arXiv:2603.13768) and is prior structure, not a finding.

### 3.5 Causal transport (M2, 113-pair cohort, 6780 cells)

Decomposition used throughout (adopted post-registration, on review):
`T = sign(Δ)/2 · (d_AB − d_BA)` (direction-odd) and `G = (d_AB + d_BA)/2`
(common-mode), where `Δ` is the donor−host endpoint gap.

| L | `real` T | `random` T | `wrong` T | `sham` T | `real` G |
|---|---|---|---|---|---|
| 8 | +1.196 ±0.200 | +0.691 | +0.303 | +0.535 | +0.009 ±0.023 |
| 10 | +1.104 ±0.197 | +0.639 | +0.260 | +0.329 | +0.018 ±0.030 |
| 12 | +1.062 | +0.516 | +0.252 | +0.395 | +0.018 |
| 14 | +0.903 | +0.426 | +0.273 | +0.433 | +0.052 |
| 16 | +0.572 | +0.247 | +0.150 | +0.307 | +0.062 |
| 18 | +0.414 | +0.257 | +0.111 | +0.158 | +0.039 |

`real` is the only condition with G ≈ 0; controls carry large |G| (`random`
+0.13…+1.13 positive, `wrong` and `sham` negative). Raw shift by host state at L8:
`real` −0.35 / +0.37 (symmetric, opposite-signed); `random` −0.07 / +1.06.

Direct paired within-pair differences (n=113) exclude zero in **all 18**
layer×control cells; e.g. L8 real−random +0.505 ±0.186, real−wrong +0.893 ±0.254,
real−sham +0.662 ±0.197.

Behavioural marker transport (full generations, L10 and L18 only, 146 discordant
cells): at **L10** real +0.781 ±0.067 vs wrong +0.425 ±0.080 — the pre-registered
`real` > `wrong_item` contrast **passes**. At **L18** real +0.322 is
indistinguishable from random +0.342 and sham +0.384 — a **null**.

Controls are **not** inert: they flip 39–50% of markers at L10. `real` is an
excess over substantial nonspecific patch effects.

Multi-draw random null (post-registered, 4068 cells, 3 draws; draw 0 reproduces
the registered draw bit-identically 1356/1356): `real` T_resid significant at all
six layers (+0.571 ±0.135 … +0.173 ±0.090); a random draw scored against its own
siblings is null at every layer.

### 3.7 `t_AB` interchange (Stage 5, 2712 cells)

Final-layer control: L31 `real` reproduces the donor margin to `0.00e+00`
(n=226); identity 678/678 exact. This gate passing is what licenses reading the
L10/L18 results as mechanistic nulls rather than pipeline failure (`rules.md` §6).

| site | `real` T | `wrong` T | `random` T |
|---|---|---|---|
| L10 `t_AB` | +0.027 ±0.028 | +0.007 | +0.010 |
| L18 `t_AB` | +0.503 ±0.120 | +0.088 | +0.035 |
| L31 `t_AB` | +1.240 ±0.200 | +0.074 | +0.023 |

At L10 the whole audio span gives T = +1.104 while the single `t_AB` position
gives +0.027. L31 is near-tautological (that residual is unembedded).

### 3.8 `t_AB` mediation (exp3-003, 1808 cells)

Endpoint = generated marker. Pair-clustered, n=73 discordant pairs.

| condition | donorward | r vs `inject_only` |
|---|---|---:|
| `identity`, `clamp_l18_only` | +0.000 | — |
| `inject_only` | +0.781 ±0.066 | 100% |
| `inject_clamp_l14` | +0.705 ±0.071 | 90.4% |
| `inject_clamp_l18` | +0.589 ±0.077 | 75.4% |

Paired differences all exclude zero. `reset_rescue` +0.349 vs `rescue_only`
+0.322, paired difference **+0.027 ±0.038 (includes zero)** — a pure rescue

the output.

### 3.9 Relay closure (exp3-004, 904 cells)

Prompt geometry: 20 pre-audio positions, 74–247 audio positions, **15 relay
positions**, 1 readout position. Clamping all 15 relay positions to host after
every block L11–L31.

Validity: `identity` 226/226 exact; **`sham_preaudio` reproduces `open`
226/226 exactly**; hooks fire once in 1- and 22-hook compositions; 1 of 904 cells
quality-flagged.

| arm | donorward |
|---|---|
| `open` | +0.781 ±0.066 |
| `relay_closed` | +0.575 ±0.065 |
| `sham_preaudio` | +0.781 ±0.066 |

**r = 0.737, 95% cluster-bootstrap CI [0.645, 0.836]** (20,000 resamples).
Frozen rule: ≤0.20 ⇒ relay necessary; ≥0.80 ⇒ R-avoiding sufficient; otherwise
mixed. **Verdict: mixed/ambiguous.** Closing the relay reversed the injected
decision in 6/73 pairs.

## 6. Claim ladder

### Supported

- Changing only the phase-handling route of the same recording changed the frozen
  explicit-refusal label in 69/350 harmful (19.7%) and 33/150 benign (22.0%)
  pairs, bidirectionally, with no marginal-rate change detectable by the
  secondary test.
- Pair-matched audio-span interchange at L8–L12 is causally effective on the
  refusal outcome, exceeding wrong-item, random-direction and position-sham
  controls at every tested layer, and exceeding each host's own multi-draw random
  baseline.
- Resetting the audio span at L12 removes ~82–97% of that effect (endpoint
  dependent).
- Neither tested intermediate answer-position state (L14, L18) is an **exclusive**
  causal bottleneck.
- The relay set of 15 prompt tokens is **not necessary**: clamping it across 21
  layers retains 73.7% of the effect (CI lower bound 0.645).

### Not supported

- **Safety specificity.** Benign (0.220) ≥ harmful (0.197); the interaction
  includes zero. Phrase as "no evidence the disagreement rate differed by harmful
  vs benign" — not detectably different, not the same.
- **"Phase alone with perceived content held constant."** Content equivalence was
  never validly evaluated; the registered gate was mis-specified and the repair is
  post-hoc.
- **A jailbreak result, or "phase changed refusal by 20 points."** ~20% is the
  paired disagreement rate; the harmful net change is −3.7 points and includes
  zero, with 28 harmful items switching *toward* refusal. The conditional 16.3%
  and 28.6% figures have different denominators and must not be compared as
  directional evidence; McNemar (41 vs 28, p = 0.148) is the correct test.
- **A discovered refusal axis.** Full spans and full states were patched, not an
  isolated one-dimensional component.
- **"The controls were null."** They are substantial; `real` is an excess.
- **"L31 is the causal locus."** That is an indexing/readout control.
- **An encoder-level refusal representation.** Harmful-only AUROC 0.512.
- **Input-level item-specificity.** M1 at n=40 cannot separate the temporal
  components from `time_shift` / `wrong_item`.
- **"The signal hands off to `t_AB` by L18."** Retracted: the L18 clamp leaves
  75.4% of the effect, and the L18 behavioural transport is a null.
- **"The effect bypasses the readout position."** Retracted: a one-time clamp is
  transient; `t_AB` can be re-conditioned at the next block.
- **"The audio positions are read repeatedly across layers."** Retracted: the
  patched positions are hybrid descendants rather than donor states, re-entry may
  come from intervening text tokens, and the 82%/25% figures differ in timing,
  duration and dimensionality so they are not comparable as percent mediated.
- **"R-avoiding routes are sufficient."** The CI [0.645, 0.836] does not reach the
  frozen 0.80 threshold. Even if it had, this would not mean "direct
  audio→readout": generated positions can attend to the audio themselves and
  relay through earlier generated positions, a third route no run has closed.
- **Generalisation beyond Qwen2-Audio**, or beyond the phase contrast. The
  `echo` / `tone` breadth arms remain disabled pending a processing-matched
  round-trip baseline (`rules.md` §4).

## 7. Open questions

1. **Content equivalence.** The registered gate was mis-specified. A blinded,
   pre-specified human input-equivalence audit over the existing 500 pairs
   requires no model inference. *The project owner stated this will be done
   separately.*
2. **Where the effect routes.** Both the relay (r = 0.737) and the L18 readout
   (75.4% retained) are individually non-necessary. The remaining untested route
   is audio → generated positions → later generated positions. Closing it
   requires attention-edge (K/V) substitution extended through decoding, which is
   the larger engineering item.
3. **Persistence curve.** Only two reset layers exist (L12 → 3.3%, L14 → 16.5%).
   `scripts/exp3/span_persistence_sweep.py` is implemented and unrun; it sweeps
   k ∈ {11,12,13,14,16,18,20,22}. Review classified this as persistence, not
   routing, and deferred rather than dropped it.
4. **Statistical ceiling.** With 73 informative clusters the best-case 95%
   half-width on a proportion is ≈11–12 points. The relay interval half-width is
   ±0.10. The frozen stop rule states that intervals straddling the material
   threshold call for more independent pairs rather than more ablations.
5. **Second model.** `configs/models/` holds MiniCPM-o-2.6, Kimi-Audio and
   Ultravox entries. MiniCPM-o and Kimi-Audio use Qwen2-family LLMs, so they give
   a second *system*, not an independent language backbone; Ultravox
   (Llama-3.1-8B) would. `hf_audio_lm.py` deliberately raises
   `NotImplementedError` for conversation adapters and readout-position
   resolution, and `exp3_qwen_mechanism.py` imports `models.qwen2_audio`
   directly in four places, so a second model requires that work first.

Notes for whoever runs this next:

- GPU stages of `run_qwen_mechanism.py` require an **immutable clean git
  checkout** and re-verify the config snapshot and commit on every resume. The
  post-hoc scripts above do not.
- The mechanism cohort is frozen per run directory; overriding cohort caps
  against an existing run is refused with "mechanism cohort changed after it was
  frozen".
- `_stratified_limit` is seeded, so re-running a stage against the same run
  selects the same pairs.
- To reuse a frozen cohort in a *new* run directory, copy `inputs/pairs.jsonl`
  and `behavior/generations.jsonl` across first; this is how
  `exp3_20260730_0200_m1_interaction` was produced.
